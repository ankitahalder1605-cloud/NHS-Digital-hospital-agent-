# 📊 NHS Digital Hospital Agent — Dataset Guide

## Dataset Source

This project is designed to use NHS England artificial/synthetic healthcare data for development and testing.

The dataset guide considers four main categories.

## 🟢 Tier 1 — Synthetic Data

- SynthEA
- NHS England artificial/synthetic datasets
- CPRD synthetic/dummy datasets

Synthetic data is preferred for development because it avoids using real patient-identifiable information.

## 🔵 Tier 2 — Open/Aggregated UK Health Data

Examples include:

- Hospital Episode Statistics (HES)
- NHS England Open Data
- OpenPrescribing
- ONS Health Data
- SNOMED CT UK Edition
- NHS Data Dictionary

## 🟠 Tier 3 — Real/Pseudonymised NHS Data

Real or pseudonymised NHS data requires appropriate access, governance and approval.

Such data should not be uploaded to a public GitHub repository without authorization.

## 🟣 Tier 4 — General Healthcare/ML Datasets

Examples include:

- MIMIC-IV
- i2b2/n2c2 datasets
- Other appropriately licensed healthcare datasets

## 📋 Dataset Review

The selected dataset will be reviewed for:

- Number of rows
- Number of columns
- Data types
- Missing values
- Duplicate records
- Invalid values
- Outliers
- Categorical variables
- Numerical variables
- Date/time variables

## 🔐 Data Privacy

No real patient-identifiable information should be uploaded to the public GitHub repository.

The project will use synthetic/artificial or appropriately licensed public data during development.

## 📊 Analytics

The dataset will be used for:

- Data cleaning
- Exploratory Data Analysis
- KPI calculation
- Trend analysis
- Visualization
- Dashboard development
- AI/ML experimentation where appropriate
